LOOP — GitHub Pages prototype

UPLOAD FIRST
1. Extract this ZIP on your phone/computer.
2. Open your GitHub repository (or create a new public repository).
3. Upload index.html to the repository root (not inside another folder).
4. Commit the upload.
5. In GitHub: Settings → Pages → Deploy from a branch → choose main and /(root) → Save.
6. Open the Pages URL after GitHub finishes publishing.

IMPORTANT LIMITATIONS
- This is a front-end prototype so you can publish/test the interface first.
- Data is saved in the current browser only (localStorage). It is NOT a real multi-user social network yet.
- The demo login is local-only and is not secure. Do not use a real password.
- Firebase Authentication, Firestore database, and Firebase Storage are NOT connected yet.
- Local image uploads are limited to 2 MB and remain in the browser. They are not uploaded to a server.
- Demo feed photos use external Unsplash URLs and need internet access.
- Real followers, cross-device accounts, secure login, and shared posts require Firebase setup next.
